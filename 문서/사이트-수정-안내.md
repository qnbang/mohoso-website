# 모호소 홈페이지 — 수정 안내

빌드 과정이 없는 순수 HTML/CSS/JS 사이트입니다. 파일을 고치면 바로 반영됩니다.

## 자주 하는 수정

### 1. 프로젝트 추가·수정
`assets/js/data.js` 한 파일만 고치면 됩니다.
- 배열 맨 앞에 추가하면 메인 그리드 첫 번째에 나옵니다 (최신순 정렬).
- 이미지는 `assets/img/works/<slug>/` 폴더에 `hero.jpg`(대표), `01.jpg`, `02.jpg`… 로 넣고
  `images` 항목에 파일명을 적습니다.

### 2. 연락처 정보 교체 (현재 임시값!)
`contact.html`에서 `TODO` 주석이 달린 세 곳(이메일·주소·전화·인스타)을 실제 정보로 바꿉니다.
`index.html`의 메타 설명, `about.html`의 소개문도 워딩 확정 후 교체하세요.

### 3. 색·여백 조정
`assets/css/style.css` 맨 위 `:root` 변수만 바꾸면 사이트 전체에 적용됩니다.
(주황 포인트색 `--accent: #ea5f2c`는 로고 원본에서 추출한 값)

## 미리보기
터미널에서:
```
cd 홈페이지
python3 -m http.server 8742
```
브라우저에서 http://localhost:8742 접속.

## 페이지 구성
- `index.html` — 메인 (프로젝트 그리드, data.js에서 자동 생성)
- `work.html?id=슬러그` — 프로젝트 상세 (자동 생성)
- `about.html` — 사무소·대표 소개, 수상 내역
- `contact.html` — 연락처
